01 — Conceptos fundamentales
📦 Conjunto
Definición
Familia (finita o infinita) de elementos.
Notación: conjuntos con MAYÚSCULAS, elementos con minúsculas.
Ejemplo: A = {2, 4, 6, 8}
Pertenencia
Relación entre un elemento y un conjunto.
a ∈ X → a pertenece a X
a ∉ X → a no pertenece a X
⚠️ Conjunto, elemento y pertenencia son términos primitivos (se aceptan sin definición formal).
📝 Formas de definir
Por extensión
Se enumeran todos los elementos.
A = {1, 2, 3}
Pares = {2, 4, 6, ...}
Por comprensión
Se da la propiedad que define los elementos.
A = {x / x ∈ ℕ ∧ x ≤ 3}
Se lee: "el conjunto de todas las x tales que..."
Diagrama de Venn
Representación gráfica con curva cerrada.
Nombre del conjunto afuera, elementos adentro.
⭐ Conjuntos especiales
Conjunto vacío
No tiene elementos. Símbolo: ∅ o { }
Conjunto unitario
Tiene un solo elemento. Ej: {3}
Cardinal de un conjunto
Cantidad de elementos: #(A)
Ej: Si A = {2, 4, 6} → #(A) = 3
Conjunto referencial / universal
Se representa con un rectángulo.
Notación: R o U
Es el conjunto del cual se toman los elementos.
02 — Conjuntos numéricos
🔢 Jerarquía de conjuntos numéricos
ℕ — Naturales
{1, 2, 3, 4, ...}
Para contar, sin el cero (según apunte oficial)
ℕ₀ — Naturales con cero
{0, 1, 2, 3, 4, ...}
Los naturales + el 0  (ℕ₀ = ℕ ∪ {0})
ℤ — Enteros
{..., -3, -2, -1, 0, 1, 2, 3, ...}
Positivos, negativos y cero (sin decimales)
ℚ — Racionales
{p/q / p ∈ ℤ ∧ q ∈ ℤ - {0}}
Expresables como fracción (incluye enteros)
𝕀 — Irracionales
π, e, √2, ...
Infinitos decimales no periódicos (no fracción)
ℝ — Reales = ℚ ∪ 𝕀
Todos los números: racionales + irracionales.  Contención: ℕ ⊂ ℕ₀ ⊂ ℤ ⊂ ℚ ⊂ ℝ
03 — Relaciones entre conjuntos
⊆ Inclusión amplia
A ⊆ B si todo elemento de A pertenece también a B.
A ⊆ B ⟺ ∀x: (x ∈ A → x ∈ B)
Contrarrecíproco: A ⊆ B ⟺ ∀x: (x ∉ B → x ∉ A)
Negación: A ⊄ B ⟺ ∃x / x ∈ A ∧ x ∉ B
⊂ Inclusión estricta
A ⊂ B si todo elemento de A está en B y existe al menos un elemento de B que no está en A.
A ⊂ B ⟺ (∀x: x∈A → x∈B) ∧ (∃x / x∈B ∧ x∉A)
= Igualdad
Dos conjuntos son iguales si tienen los mismos elementos.
A = B ⟺ A ⊆ B ∧ B ⊆ A
{1, 3, 5} = {1, 3, 5, 1, 5} (no importan repetidos)
📌 Propiedades importantes
• El conjunto vacío está incluido en todos los conjuntos: ∅ ⊆ A, ∀A
• El conjunto vacío es único
• Si A ⊆ B → A ∩ B = A
• Si A ⊆ B → A ∪ B = B
04 — Conjunto de partes (potencia)
𝒫 Conjunto potencia
P(A) es el conjunto formado por todos los subconjuntos de A.
P(A) = {X / X ⊆ A}
Ejemplo: Si A = {1, 2, 3}
P(A) = {∅, {1}, {2}, {3}, {1,2}, {1,3}, {2,3}, {1,2,3}}
Cardinal: #P(A) = 2#(A)  →  2³ = 8 subconjuntos
Si X ∈ P(A) → X ⊆ A  (sus elementos son conjuntos)
Siempre: A ∈ P(A)  y  ∅ ∈ P(A)
05 — Operaciones entre conjuntos
∩ Intersección
A ∩ B
Elementos que pertenecen a AMBOS conjuntos
A ∩ B = {x / x ∈ A ∧ x ∈ B}
Ej: A={2,4,6}, B={2,5,7} → A∩B = {2}
Disjuntos: A ∩ B = ∅ (no tienen elementos en común)
∪ Unión
A ∪ B
Elementos que pertenecen a A, a B, o a ambos
A ∪ B = {x / x ∈ A ∨ x ∈ B}
Ej: A={2,4,6}, B={2,5,7} → A∪B = {2,4,5,6,7}
− Diferencia
A − B
Elementos de A que NO pertenecen a B
A − B = {x / x ∈ A ∧ x ∉ B}
Ej: A={2,4,6}, B={2,5,7} → A−B = {4,6}  |  B−A = {5,7}
⚠️ A−B ≠ B−A (NO es conmutativa)  |  Si A⊆B → A−B = ∅
△ Diferencia simétrica
A △ B
Elementos de A o B, pero NO de ambos
A △ B = (A − B) ∪ (B − A)
A △ B = (A ∪ B) − (A ∩ B)
Ej: A={1,2,3,4}, B={2,3,5,7} → A△B = {1,4,5,7}
Aᶜ Complemento
Todos los elementos del referencial que no pertenecen a A.
Aᶜ = R − A
Notación: Aᶜ o A' o Ā
Propiedades:
1. (∅)ᶜ = R
2. Rᶜ = ∅
3. (Aᶜ)ᶜ = A  (involución / doble complemento)
06 — Propiedades de las operaciones
📐 Leyes / Propiedades de conjuntos
⚡ FINAL · Son las mismas leyes de lógica con otra notación. NO van en hoja permitida — se rinden de memoria (en mesa solo se permiten las tablas de verdad). Reconocer la ley correcta es lo que se evalúa y lo que te ahorra la cuenta.
Ley Con ∪ (unión) Con ∩ (intersección)
Idempotencia A ∪ A = A A ∩ A = A
Conmutativa A ∪ B = B ∪ A A ∩ B = B ∩ A
Asociativa (A ∪ B) ∪ C = A ∪ (B ∪ C) (A ∩ B) ∩ C = A ∩ (B ∩ C)
Distributiva (A ∩ B) ∪ C = (A∪C) ∩ (B∪C) (A ∪ B) ∩ C = (A∩C) ∪ (B∩C)
Elem. neutro A ∪ ∅ = A A ∩ R = A
Dominación A ∪ R = R A ∩ ∅ = ∅
Absorción A ∪ (A ∩ B) = A A ∩ (A ∪ B) = A
Inversa (complemento) A ∪ Aᶜ = R A ∩ Aᶜ = ∅
De Morgan (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ
Doble complemento (Aᶜ)ᶜ = A   (involución)
⚠️ Propiedad de la diferencia — clave para simplificaciones
A − B  =  A ∩ Bᶜ
Transforma una resta en una intersección → permite aplicar las leyes de la tabla.
Equivale a la implicación en lógica: p → q ≡ ¬p ∨ q

07b — Demostración y simplificación de igualdades ⚡ tema del final — casi no entró en parciales
🛠️ Tres formas de demostrar / simplificar
1 · Algebraico
Transformar un miembro aplicando leyes (tabla de la sección 06) hasta llegar al otro. Truco clave: A − B = A ∩ Bᶜ para poder usar las leyes.
2 · Por lógica
Traducir a proposiciones con la correspondencia (sección 07), aplicar equivalencias lógicas y volver a conjuntos. Es el método del apunte para De Morgan.
3 · Doble inclusión
A = B ⟺ A ⊆ B ∧ B ⊆ A. Se toma x genérico y se prueba que estar en un lado implica estar en el otro (element-chasing).
✍️ Ejemplo · Simplificar
Simplificar  (A ∩ B) ∪ (A ∩ Bᶜ)
(A ∩ B) ∪ (A ∩ Bᶜ)inicial
= A ∩ (B ∪ Bᶜ)distributiva (factor A)
= A ∩ Rinversa: B ∪ Bᶜ = R
= Aneutro de ∩  ∎
✍️ Ejemplo · Demostrar igualdad (por leyes)
Probar que  (A ∪ B) − B = A − B
(A ∪ B) − Binicial
= (A ∪ B) ∩ Bᶜresta → intersección
= (A ∩ Bᶜ) ∪ (B ∩ Bᶜ)distributiva
= (A ∩ Bᶜ) ∪ ∅inversa: B ∩ Bᶜ = ∅
= A ∩ Bᶜ = A − Bneutro de ∪  ∎
🔗 Ejemplo · Demostrar por lógica — De Morgan
Probar que  (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
x ∈ (A ∪ B)ᶜ
⟺ ¬(x∈A ∨ x∈B)def. ᶜ y ∪
⟺ ¬(x∈A) ∧ ¬(x∈B)De Morgan lógico
⟺ x ∈ Aᶜ ∩ Bᶜdef. ᶜ y ∩  ∎
🧩 Puente con el parcial
En el 1er parcial (P4d) solo pedían "expresar con una fórmula equivalente": Aᶜ ∩ Bᶜ = (A ∪ B)ᶜ.

En el final hay que justificar/demostrar ese paso (como acá), no solo escribir el resultado.
💡 Cómo encarar una demostración en el final
★ Primero pasá toda resta a intersección: A − B = A ∩ Bᶜ. Recién ahí aplicás las leyes.
★ Trabajá un solo miembro a la vez; no toques los dos en simultáneo.
★ Justificá cada paso con el nombre de la ley — eso es lo que se corrige. Las leyes van de memoria.
★ Si te trabás con el álgebra, pasá a lógica (sección 07) o demostrá por doble inclusión.
08 — Problemas de conteo (cardinal)
📊 Fórmula para 2 conjuntos
#(A ∪ B) = #A + #B − #(A ∩ B)
¿Por qué se resta? Al sumar #A + #B, la intersección se cuenta 2 veces → hay que restarla una vez.
Ejemplo: 40 alumnos entran a la facultad. 30 cursan Análisis I, 35 cursan Sist. y Métodos.
40 = 30 + 35 − X → X = 25 cursan ambas
📊 Fórmula para 3 conjuntos
#(A∪B∪C) = #A + #B + #C
− #(A∩B) − #(A∩C) − #(B∩C)
+ #(A∩B∩C)
Lógica: sumo todos los cardinales individuales, resto las 3 intersecciones dobles (se contaron 2 veces), sumo la intersección triple (se borró de más).
🎯 Método gráfico — pasos para resolver
1. Dibujar los diagramas de Venn con el universal (rectángulo).
2. Colocar primero la intersección triple (centro), luego las dobles, luego lo exclusivo de cada conjunto.
3. Verificar: la suma de TODAS las regiones (incluyendo lo que queda fuera) = #(Universal).
4. Ojo con "solo": "solo A y B" = intersección doble sin la triple. "A y B" (sin "solo") = toda la intersección incluyendo la triple.
💡 Tips de clase — claves para el final
★ Siempre dibujar el gráfico de Venn — ayuda a visualizar y verificar.
★ "Solo" ≠ sin "solo": distinguir intersecciones exclusivas de las que incluyen la triple.
★ Se puede resolver con fórmula O con gráfico — a veces uno es más fácil que el otro.
★ Para simplificar: transformar restas en intersecciones con complemento (A−B = A∩Bᶜ) y aplicar leyes.
★ Las propiedades de conjuntos son las mismas que las de lógica con otro nombre — las usás igual para simplificar y demostrar (ver sección 07b).
⚡ del final (oral 2026-06-16) · Para el final las propiedades NO van en la hoja permitida — van de memoria. Y ahora sí entran: en los parciales casi no se tomaron, pero en el final pesan. Reconocer una propiedad te ahorra la cuenta.
★ Orden de operaciones: primero paréntesis, luego complemento, luego ∩, luego ∪ (igual que en mate).
09 — Relaciones binarias 🗓️ FINAL solo desde la 3ª fecha (13-jul) · en 30-jun y 6-jul no se toma
🔗 Definición de relación
Una relación binaria R de un conjunto A en un conjunto B es un subconjunto del producto cartesiano A × B.
R ⊆ A × B
Producto cartesiano
A × B = {(a, b) / a ∈ A ∧ b ∈ B}
Conjunto de todos los pares ordenados posibles.
Ej: A={1,2}, B={a,b} → A×B = {(1,a),(1,b),(2,a),(2,b)}
⚠️ A×B ≠ B×A (el orden importa en los pares)  |  #(A×B) = #A · #B
✏️ Notación y representación
Si (a, b) ∈ R, se escribe aRb ("a está relacionado con b")
Formas de representar
Por extensión: R = {(1,2), (2,3), (3,3)}
Diagrama sagital: flechas de elementos de A hacia B
Matriz booleana: tabla con 1 si (a,b) ∈ R, 0 si no
Grafo dirigido: nodos con flechas (cuando A = B)
09b — Clasificación de relaciones (sobre un mismo conjunto A)
↩️ Reflexiva
Todo elemento está relacionado consigo mismo.
∀a ∈ A: aRa
Ej: R = "≤" sobre ℕ → 3≤3 ✓, 5≤5 ✓
Matriz: diagonal principal toda con 1
Grafo: todos los nodos tienen bucle (lazo)
Irreflexiva: ningún elemento se relaciona consigo mismo. ∀a: ¬(aRa)
Ej: R = "<" estricto → 3<3 es falso ✓
↔️ Simétrica
Si a se relaciona con b, entonces b se relaciona con a.
∀a,b ∈ A: aRb → bRa
Ej: R = "es hermano de" → si aRb entonces bRa ✓
Matriz: simétrica respecto a la diagonal (M = Mᵀ)
Grafo: si hay flecha a→b, hay flecha b→a
🚫 Antisimétrica
Si a se relaciona con b y b se relaciona con a, entonces a = b.
∀a,b ∈ A: (aRb ∧ bRa) → a = b
Ej: R = "≤" → si a≤b y b≤a entonces a=b ✓
Matriz: si M[i][j]=1 y M[j][i]=1 → i=j (solo en diagonal)
Grafo: no hay flechas dobles entre nodos distintos
⚠️ Simétrica y antisimétrica NO son opuestas — una relación puede ser ambas (ej: la igualdad) o ninguna.
➡️ Transitiva
Si a se relaciona con b, y b con c, entonces a se relaciona con c.
∀a,b,c ∈ A: (aRb ∧ bRc) → aRc
Ej: R = "≤" → si 2≤5 y 5≤8, entonces 2≤8 ✓
Grafo: si hay camino a→b→c, hay flecha directa a→c
🔍 ¿Cómo verificar?
Reflexiva: revisar que (a,a) ∈ R para cada a ∈ A
Simétrica: para cada (a,b) ∈ R verificar que (b,a) ∈ R
Antisimétrica: buscar pares (a,b) y (b,a) con a≠b → no deben existir
Transitiva: para cada cadena aRb y bRc, verificar aRc
⭐ Tipos especiales de relaciones
Relación de equivalencia
Reflexiva ✓ + Simétrica ✓ + Transitiva ✓
Ej: "tener la misma edad", "≡ (mod n)"
Genera clases de equivalencia: parten el conjunto en grupos disjuntos que lo cubren entero (una partición).
Relación de orden parcial
Reflexiva ✓ + Antisimétrica ✓ + Transitiva ✓
Ej: "≤" sobre ℕ, "⊆" entre conjuntos
Orden total si además ∀a,b: aRb ∨ bRa
