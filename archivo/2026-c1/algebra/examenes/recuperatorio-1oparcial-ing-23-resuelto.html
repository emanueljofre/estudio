Operaciones lógicas · simbolización — 20 pts

Llevar a forma simbólica

Enunciado
  • Arreglaré mi techo o no pagaré el alquiler.
  • Sigue el mal tiempo, mañana no iré a caminar y seguiré estudiando para el parcial.
Cómo simbolizar
  • Asigná una letra a cada proposición simple (afirmativa). El "no" se simboliza con ~ sobre la letra correspondiente.
  • "o" → ∨ · "y" → ∧ · "si… entonces / cuando…," → →.
  • Una coma que separa una causa de su consecuencia suele esconder un → ("(si) sigue el mal tiempo, (entonces)…").
Frase 1 — "Arreglaré mi techo o no pagaré el alquiler"
  1. Proposiciones: p = arreglaré mi techo · q = pagaré el alquiler.
  2. "p o no q" → conjunción de disyunción con la segunda negada.
Respuesta · frase 1

p ∨ ~q

Frase 2 — "Sigue el mal tiempo, mañana no iré a caminar y seguiré estudiando…"
  1. Proposiciones: r = sigue el mal tiempo · s = iré a caminar · t = seguiré estudiando para el parcial.
  2. La coma marca causa → consecuencia: "(si) sigue el mal tiempo, entonces (no iré a caminar) y (seguiré estudiando)".
  3. Consecuente compuesto: ~s ∧ t. Todo: r → (~s ∧ t).
Respuesta · frase 2

r → (~s ∧ t)

⚠ Interpretación

El enunciado no dice "si" explícito. Lo leí como condicional r → (~s ∧ t) (la coma actúa de "entonces"). Si tu cátedra lo toma como una simple enumeración de hechos, sería una conjunción: r ∧ ~s ∧ t. La versión condicional es la estructura más probable que buscan.

Conjuntos · extensión y comprensión — 30 pts

Definir conjuntos

Enunciado

a) Definir por extensión: { x / x ∈ ℝ ∧ x² = 4 }

b) Definir por comprensión: { −3, 0, 3, 6, 9, … }

Extensión vs. comprensión
  • Por extensión: se listan los elementos entre llaves → {a, b, c}.
  • Por comprensión: se da la regla / propiedad que cumplen → { x / x cumple P(x) }.
  • Pasar de comprensión a extensión = resolver la condición; al revés = encontrar el patrón.
a) Pasar a extensión
  1. La condición es x² = 4 con x ∈ ℝ.
  2. Resolvemos: x = ±√4 = ±2 → dos soluciones reales, x = 2 y x = −2.
Respuesta · a)

Por extensión: { −2, 2 }

b) Pasar a comprensión
  1. Observamos el patrón: −3, 0, 3, 6, 9, … → van de 3 en 3 (progresión aritmética de paso 3).
  2. Son los múltiplos de 3 desde −3 hacia arriba (incluye negativos solo hasta −3). Es un conjunto infinito.
  3. Regla: x = 3k con k entero y k ≥ −1 (porque 3·(−1) = −3 es el menor).
Respuesta · b)

Por comprensión: { x ∈ ℤ / x = 3k, k ∈ ℤ, k ≥ −1 }

Equivalente: { x ∈ ℤ / x es múltiplo de 3 ∧ x ≥ −3 }.

Conjuntos · operaciones gráficas — 30 pts

Sombrear e identificar regiones

Enunciado

a) Sombrear el recinto resultante de la operación (A ∩ B) ∪ C.

b) Indicar la operación cuyo resultado es el recinto sombreado (diagrama dado).

Recordatorio de operaciones
  • A ∩ B = solo lo que está en ambos (la lente). · A ∪ B = todo lo de A o de B.
  • A − B = lo que está en A pero no en B (le "recortás" a A la parte que toca B).
  • Para a): primero la lente A ∩ B, después le sumás todo C.
a) (A ∩ B) ∪ Cla lente A∩B + todo el círculo C
b) Región dada = B − Atodo B menos lo que comparte con A
  1. a) Sombreamos la intersección A ∩ B y, además, la totalidad de C. La unión hace que ambas zonas queden pintadas.
  2. b) En el diagrama dado, lo sombreado es la parte de B que no pisa A (la lente A ∩ B queda en blanco). Eso es exactamente B − A.
Respuesta modelo

a) Se sombrea (A ∩ B) ∪ C (ver figura izquierda).

b) La operación es B − A  (equivalente: B ∩ Aᶜ).

⚠ Interpretación

En el original, los símbolos ∩ / ∪ de a) no se exportaron del Word con certeza; tomé la lectura más natural (A ∩ B) ∪ C. Si en tu hoja figura otra combinación (p. ej. (A ∪ B) ∩ C), avisame y rehago el sombreado.

Problemas de conteo · inclusión-exclusión — 20 pts

Instituto de idiomas

Enunciado

Instituto con 1500 inscriptos. Estudian al menos uno de los tres idiomas: 1200. Datos: |I| = 600, |P| = 525, |F| = 450, |I∩P| = 150, |P∩F| = 195, |I∩F| = 120. (I = inglés, P = portugués, F = francés.)

a) ¿Cuántos estudian los 3 idiomas? b) ¿Cuántos no se decidieron por ninguno? c) Diagrama de Venn.

Principio de inclusión-exclusión (3 conjuntos)

|I ∪ P ∪ F| = |I| + |P| + |F| − |I∩P| − |I∩F| − |P∩F| + |I∩P∩F|

  • Se suman los individuales, se restan los pares (contados de más) y se vuelve a sumar el triple (restado de más).
  • El dato |I∪P∪F| = 1200 es "al menos uno"; lo usamos para despejar el triple.
  • "Ninguno" = total − los que estudian al menos uno.
a) Despejar el triple (los 3 idiomas)
1200 = 600 + 525 + 450 − 150 − 120 − 195 + xinclusión-exclusión
⟹1200 = 1575 − 465 + xsumas: indiv. 1575 ; pares 465
⟹1200 = 1110 + x1575 − 465 = 1110
⟹x = 90estudian los 3 idiomas
b) Los que no estudian ninguno
1500 − 1200 = 300total − (al menos uno)
c) Diagrama de Venn (todas las regiones)

A cada par le restamos el triple, y a cada individual le restamos sus dos pares y el triple:

Ninguno (fuera): 300suma de las 7 regiones = 1200
Respuesta modelo

a) Estudian los 3 idiomas: 90 alumnos.

b) No estudian ninguno: 300 alumnos.

Verificación: 420+60+270+30+90+105+225 = 1200 ✓  y  1200 + 300 = 1500 ✓
