Bases y dimensión

Una base es un sistema de referencia ordenado: con ella cada vector, sea de ℝⁿ, una matriz o un polinomio, se vuelve una columna de números. La dimensión es el largo de esa columna, y cambiar de base es multiplicar por una matriz.

Base: independiente y generadora

★ lo que siempre hay que probar

Una base tiene los vectores justos: ninguno sobra y alcanzan para todo el espacio.

1.1 La definición: dos condiciones

Definición 1.1Base de un espacio vectorial
F1 · llevable
B es base de VB = {v₁, …, vn} ⊂ V:  (I) B es LI  y  (II) gen(B) = V
Canónica de ℝ²(a, b) = a(1, 0) + b(0, 1)

LI quiere decir que ningún vector sobra: la única combinación que da el cero es la de coeficientes nulos. Generar quiere decir que alcanzan: todo vector del espacio es combinación de los de B.

Ni de menos ni de más: la base es el punto justo

"lo que siempre voy a tener que estar probando cuando tengo una base, es esas 2 cosas: que generen y que sean linealmente independientes."— el profe, clase 15/10
Unicidad Por el Teorema 1.1 del apunte, con una base cada vector se escribe de una sola manera: restando dos escrituras, la LI obliga a que los coeficientes coincidan. Eso permite hablar de las coordenadas (§4.1).

1.2 Contar antes de probar

Teoremas 1.3 y 1.5La cantidad justa de vectores
F2 · llevable
T1.3dim V = n  ⟹  un conjunto LI tiene a lo sumo n vectores; más de n es LD
T1.5dim V = n,  {v₁, …, vn} LI  ⟹  {v₁, …, vn} es base de V

Con la dimensión conocida: n vectores LI ya son base, y no hace falta probar que generan. Más de n no es base porque son LD; menos de n tampoco, porque no generan.

Ejemplo de la clase¿B = {(2, 1), (1, −1)} es base de ℝ²?
1 · LIno son múltiplos: si (1, −1) = k(2, 1), la primera da k = 12 y la segunda k = −1
2 · contar2 vectores LI en ℝ², que tiene dimensión 2
conclusiónB es base de ℝ² (Teorema 1.5)

Con tres vectores de ℝ³ la LI sale de un determinante: en el deck, {(2, 5), (1, 3)} da det = 6 − 5 = 1 ≠ 0, así que es base de ℝ².

Vale puntos: decir por qué son LI La palabra «base» sin la justificación de la LI pierde el punto. Escribí el motivo: no son múltiplos, el determinante no es cero, o el sistema homogéneo tiene solo la trivial. Citar el teorema que se usa es justificación completa.
"Estas son cosas que ustedes tienen que justificar si no les queda mal el punto."— el profe, clase 21/10
Teorema 1.3 en la U08 Es el Teorema 4 de la hoja de la U08: más vectores que componentes es LD.

Base y dimensión de un subespacio

★ el ejercicio que ya entró dos veces

Un subespacio dado por condiciones se convierte en una base con el mismo método de la U08, más un paso: probar la LI y contar.

2.1 El método que no falla

ProcedimientoBase y dimensión de un subespacio dado por condiciones
  1. Despejar las variables dependientes en función de las libres
  2. Escribir el elemento genérico solo con las libres
  3. Separar por variable libre: los vectores que multiplican a cada libre generan
  4. Probar la LI de esos vectores
  5. Cerrar: base = esos vectores; dim = cuántos son
F3 · llevabledim S = cantidad de variables libres = incógnitas − ecuaciones independientes
Ejemplo de la clase y del deckS = {(x, y, z) ∈ ℝ³ : 2x − y + 3z = 0}
1 · despejary = 2x + 3z
2 · genérico(x, y, z) = (x, 2x + 3z, z)
3 · separar= x(1, 2, 0) + z(0, 3, 1)  ← generan S
4 · LIno son múltiplos: la primera componente es 1 en uno y 0 en el otro
respuestaBS = {(1, 2, 0), (0, 3, 1)},  dim S = 2

Control: el plano tiene dimensión 2 ≤ 3 = dim ℝ³ (Teorema 1.4), y 3 incógnitas menos 1 ecuación dan 2 libres.

"Es como el método que vamos a ver siempre, porque no falla."— el profe, clase 15/10
"este es bastante parecido a uno que podría ser en un parcial."— el profe, clase 15/10

2.2 Matrices y polinomios: el mismo método

Ejemplo de la claseMatrices simétricas 2×2
1 · genéricoW = { abbc }  ← la entrada repetida ya es la condición
2 · separara1000 + b0110 + c0001
3 · LIigualada a la matriz nula, cada entrada da α = 0, β = 0, γ = 0
respuestaesas tres matrices son base; dim W = 3 ≤ 4 = dim ℝ²ˣ²
Ejemplo de la claseS = {p ∈ P₂ : p(1) = 0}
1 · condiciónp = ax² + bx + c,  p(1) = a + b + c = 0  ⟹  a = −b − c
2 · separarp = (−b − c)x² + bx + c = b(−x² + x) + c(−x² + 1)
3 · LIno son múltiplos: uno tiene término en x y el otro no
respuestaBS = {−x² + x, −x² + 1},  dim S = 2
Vale puntos: comprobar o demostrar Si antes de la base el enunciado pide ver que S es subespacio, el verbo manda: comprobar admite ejemplos; demostrar pide elementos arbitrarios.
Notación El deck escribe M2×2(ℝ); el profe dice «ℝ dos por dos». Esta hoja escribe ℝ²ˣ².

Dimensión

Todas las bases de un espacio tienen la misma cantidad de vectores. Ese número es la dimensión.

3.1 Definición y Teorema 1.2

Definición 1.2 y Teorema 1.2La dimensión no depende de la base
F4 · llevable
T1.2B₁ y B₂ bases de V  ⟹  |B₁| = |B₂|
Dimensióndim V = |B| para cualquier base B de V;  dim{0} = 0
Generalesdim ℝⁿ = n,  dim ℝm×n = mn,  dim Pn = n + 1

{(1, 0, 0), (0, 1, 0), (0, 0, 1)} y {(1, 0, 0), (1, 1, 0), (1, 1, 1)} son dos bases de ℝ³: cambian los vectores, la dimensión no.

EspacioBase canónica, en este ordendim
ℝ²{(1, 0), (0, 1)}2
ℝ³{e₁, e₂, e₃}3
ℝ⁴{e₁, e₂, e₃, e₄}4
ℝ²ˣ²{E₁₁, E₁₂, E₂₁, E₂₂}: un 1 en esa entrada, el resto 04
P₁{1, x}2
P₂E = {1, x, x²}3
{0}sin vectores0
"La dimensión de S va a ser el cardinal de cualquier base [...] la cantidad de elementos que tiene una base."— el profe, clase 15/10
Para qué sirve la tabla Es la n que piden los teoremas 1.3 y 1.5 (F2): sabiendo que dim ℝ²ˣ² = 4, cinco matrices nunca son LI.

3.2 Un subespacio nunca es más grande

Teorema 1.4Dimensión de un subespacio
F5 · llevableH subespacio de V,  dim V finita  ⟹  dim H ≤ dim V

Sirve de control al final de un ejercicio: un plano de ℝ³ tiene dim 2 ≤ 3; las simétricas, 3 ≤ 4. Si la cuenta da una dimensión mayor que la del espacio, hay un error.

Auto-test¿Qué dos cosas hay que probar para decir que B es base de V? ¿Cuál podés saltear si sabés dim V?
Que B es LI y que genera V. Si B tiene exactamente dim V vectores, alcanza con la LI (Teorema 1.5).
Demostraciones Los apuntes demuestran los teoremas 1.1 a 2.2; el profe no dictó ninguna demostración en clase. Se citan, no se prueban.

Coordenadas en una base

Los coeficientes que escriben un vector en una base, puestos en columna, son sus coordenadas: el vector traducido a ℝⁿ.

4.1 Definición y cálculo

DefiniciónVector de coordenadas
F6 · llevable
CoordenadasB = {v₁, …, vn} base ordenada,  x = c₁v₁ + ⋯ + cnvn  ⟹  [x]B = (c₁, …, cn)ᵀ
Linealidad[αu + βv]B = α[u]B + β[v]B

Se calculan con un sistema: los vectores de la base como columnas y x como término independiente. Siempre tiene solución única, porque B es base.

Ejemplo de la clase[(5, 1)]B con B = {(2, 1), (1, −1)}
1 · plantearα(2, 1) + β(1, −1) = (5, 1):  2α + β = 5α − β = 1
2 · resolversumando: 3α = 6,  α = 2,  β = 1
respuesta[(5, 1)]B = (2, 1)ᵀ

Verificación: 2(2, 1) + 1(1, −1) = (5, 1) ✓.

El vector no se mueve: cambia la base con la que se lo mide

Tupla o columna El profe escribe los vectores como tupla y las coordenadas en columna, para distinguir de qué se habla. Escribirlas como tupla también vale.
"podría usar sus coordenadas que van a ser siempre en R², en R³ o en R⁴. Eso me ayuda mucho con las cuentas."— el profe, clase 15/10

4.2 Matrices y polinomios: una ecuación por entrada

Ejemplo de la claseM = 4−1−13 en B₂ = { 1000, 1110, 1111 }
1 · entradasα + β + γ = 4β + γ = −1γ = 3  ← las dos entradas iguales dan la misma ecuación
2 · hacia atrásγ = 3,  β = −4,  α = 5
respuesta[M]B₂ = (5, −4, 3)ᵀ

En la canónica de P₂, las coordenadas son los coeficientes en el orden de la base: [4 − 3x + 5x²]E = (4, −3, 5)ᵀ. En ℝ²ˣ², cada entrada es el coeficiente de su Eij.

ProposiciónLa LI se decide en ℝⁿ
F7 · llevableB base de V:  {w₁, …, wk} LI en V  ⟺  {[w₁]B, …, [wk]B} LI en ℝⁿ

Con polinomios o matrices: se pasan a coordenadas en la canónica, se ponen en columnas y se calcula el determinante. Para A = {1, 1 + x, 1 + x + x²}, las columnas (1, 0, 0), (1, 1, 0) y (1, 1, 1) dan det = 1 ≠ 0: tres LI en dimensión 3, es base.

Contraejemplo del deck {x, x², x + x²} no es base: el tercero es la suma de los otros dos.

4.3 Las bases son ordenadas

TrampaMismo conjunto, otro orden: otra base

Con B = {(2, 1), (1, −1)}, [(5, 1)]B = (2, 1)ᵀ; con B′ = {(1, −1), (2, 1)}, [(5, 1)]B′ = (1, 2)ᵀ. El final del 11/02/2026 dio la canónica de P₂ como {x², x, 1}, al revés del deck: ahí [4 − 3x + 5x²] = (5, −3, 4)ᵀ. Leé el orden del enunciado antes de escribir una sola coordenada.

Auto-testE = {1, x, x²} y E′ = {x², x, 1}. ¿Cuánto vale [3 − x + 2x²] en cada una?
(3, −1, 2)ᵀ en E y (2, −1, 3)ᵀ en E′. Son las mismas coordenadas permutadas, y no son intercambiables.
"Las bases son ordenadas, es decir, que las coordenadas que yo pueda escribir en B no son iguales a las coordenadas de B prima."— el profe, clase 15/10
"generan lo mismo, pero no es la misma base. Son bases distintas."— el profe, clase 21/10
5

Matriz de cambio de base

★ la propiedad que sigue en transformaciones

Una matriz traduce las coordenadas de un vector de una base a otra. Sus columnas son la base de origen escrita en la de destino.

5.1 Se arma por columnas

DefiniciónMatriz de cambio de base de B₁ a B₂
F8 · llevable
DatosB₁ = (u₁, …, un),  B₂ = (v₁, …, vn) bases ordenadas de V
Matriz n × nPB₁→B₂ = ( [u₁]B₂  [u₂]B₂  ⋯  [un]B₂ )

Cada vector de B₁ se escribe en B₂ y esa columna se pone en el lugar que ocupa en B₁: origen escrito en el destino.

Ejemplo del deckB₁ = {(4, 1), (1, 2)},  B₂ = {(1, 1), (−1, 2)}
1 · u₁ en B₂(4, 1) = 3(1, 1) − 1(−1, 2)  ⟹  [u₁]B₂ = (3, −1)ᵀ
2 · u₂ en B₂(1, 2) = 43(1, 1) + 13(−1, 2)  ⟹  [u₂]B₂ = (43, 13)ᵀ
respuestaPB₁→B₂ = 3−14313

En ℝ³ son tres sistemas con la misma matriz de coeficientes, los vectores de B₂ en columnas. Se resuelven juntos, ampliando con tres columnas de términos independientes.

Notación El deck escribe P₁₂ y la llama matriz de transición; el apunte, PB₁→B₂ «o simplemente A»; el profe dice «matriz cambio de base». Esta hoja escribe PB₁→B₂, que dice la dirección.
"siempre las coordenadas son columnas, o sea que acá va todo en columna."— el profe, clase 15/10

5.2 La ecuación y su dirección

Teorema 2.1Cómo se usa la matriz
F9 · llevable[x]B₂ = PB₁→B₂ · [x]B₁

Con la matriz de §5.1 y [x]B₁ = (3, −2)ᵀ: (9 − 83, −3 − 23)ᵀ = (193, −113)ᵀ. El vector es el mismo: 3(4, 1) − 2(1, 2) = (10, −1), y también 193(1, 1) − 113(−1, 2) = (10, −1) ✓.

TrampaMultiplicar la matriz por las coordenadas equivocadas

PB₁→B₂ recibe coordenadas en B₁, el origen. En la clase grabada se dijo al revés: con B₁ = {(1, 0, 0), (1, 1, 0), (1, 1, 1)}, B₂ = {(1, 2, 0), (0, 1, 1), (1, 0, 1)} y [v]B₁ = (2, −1, 3)ᵀ, se multiplicó por la inversa y salió (2, 1, 2)ᵀ. Lo correcto es

1 · ecuación[v]B₂ = 131−222−11112 (2, −1, 3)ᵀ = (1, 0, 3)ᵀ
2 · chequeo2(1, 0, 0) − (1, 1, 0) + 3(1, 1, 1) = (4, 2, 3) = 1(1, 2, 0) + 0(0, 1, 1) + 3(1, 0, 1) ✓

Con (2, 1, 2)ᵀ la reconstrucción da (4, 5, 3): otro vector. Reconstruí el vector con las dos coordenadas; si no coinciden, la dirección está mal.

Auto-testTenés PB₁→B₂ y [x]B₂. ¿Qué cuenta te da [x]B₁?
[x]B₁ = (PB₁→B₂)⁻¹[x]B₂ = PB₂→B₁[x]B₂. Multiplicar PB₁→B₂ por coordenadas en B₂ es el error de la trampa.
"esto es súper importante. Es una propiedad que nos va a acompañar también en transformaciones lineales."— el profe, clase 15/10
Qué dicen las fuentes El deck (Teorema 2.1) y el apunte del profe escriben la ecuación como F9. En el ejercicio con parámetro de la misma clase, el profe usa la dirección correcta (§6.2).

5.3 Siempre es invertible

Teorema 2.2La inversa hace el cambio al revés
F10 · llevable(PB₁→B₂)⁻¹ = PB₂→B₁

Sus columnas son coordenadas de una base, que son LI (F7): el determinante no es cero. En el ejemplo de §5.1, det = 1 + 43 = 73 y PB₂→B₁ = 1713−49, que lleva (193, −113)ᵀ de vuelta a (3, −2)ᵀ.

Cada flecha recibe las coordenadas de donde sale

Vale puntos: la inversa con calculadora En el examen la inversa numérica puede salir con calculadora: se escribe que se está invirtiendo y se da el resultado, sin demostrar nada. Con un parámetro no hay calculadora: va a mano (§6.2).
"si yo agarro P de B₁ a B₂ y calculo su inversa, esto me da el cambio de base al revés [...] Esto es muy importante para hacer la menor cantidad de cuentas posibles."— el profe, clase 15/10

El atajo de la canónica y el parámetro

Si una de las dos bases es la canónica, la matriz se escribe sin cuentas: sus columnas son los vectores de la otra base.

6.1 C y C⁻¹

Procedimiento prácticoCambio de base con la canónica
F11 · llevable
Cmatriz con los vectores de B en columnas (en P₂, los coeficientes de 1, x, x²)
De B a EPB→E = C,  x = C[x]B
De E a BPE→B = C⁻¹,  [x]B = C⁻¹x

Funciona porque en la canónica cada vector es sus propias coordenadas. Ejemplo del deck en ℝ²: con B = {(1, 1), (1, −1)}, C(3, 1)ᵀ = (4, 2)ᵀ y C⁻¹(4, 2)ᵀ = (3, 1)ᵀ, la figura de §4.1.

Final 18/12/2024 · P4 · ENTRÓ 2024Matriz de cambio de base en P₂

En P₂, con la canónica {1, x, x²} y B = {1 + x, x + x², x²}: encontrá la matriz de cambio de base de B a la canónica. Si p(x) = 2 + 3x + 4x², expresá p en la base B.

1 · columnas[1 + x]E = (1, 1, 0)ᵀ,  [x + x²]E = (0, 1, 1)ᵀ,  [x²]E = (0, 0, 1)ᵀ
2 · de B a EPB→E = C = 110011001  ← det = 1: B es base
3 · de E a B[p]B = C⁻¹[p]E = 1−1101−1001 (2, 3, 4)ᵀ = (2, 1, 3)ᵀ
respuestap = 2(1 + x) + 1(x + x²) + 3x²  ✓

Vale puntos: las columnas en el orden de B, la matriz pedida y la reconstrucción de p. «De B a la canónica» es C, no C⁻¹.

Resolución de la hoja El final no tiene clave del profe. La parte b también sale por sistema, igualando coeficientes: es la que resuelve la hoja de la U08.

6.2 Cambio de base con parámetro

Ejercicio de la claseB = {v₁, v₂, v₃},  w₁ = v₁ + kv₂,  w₂ = v₂ + kv₃,  w₃ = kv₁ + v₃
  1. Coordenadas leídas de la definición: [w₁]B = (1, k, 0)ᵀ, [w₂]B = (0, 1, k)ᵀ, [w₃]B = (k, 0, 1)ᵀ, así que PB′→B = 1k001kk01
  2. ¿Es base? det = 1 + k³ ≠ 0 ⟺ k ≠ −1. Por F7 los wi son LI, y tres LI en dimensión 3 son base (F2)
  3. Invertir a mano (Gauss-Jordan contra la identidad): PB→B′ = 1k³ + 11−kk²k²1−k−kk²1

7.1 Las claves

  1. Base = LI + genera, y la LI siempre justificada. F1
  2. n LI en dimensión n ya son base; más o menos de n, no. F2
  3. Subespacio con condiciones: despejar, separar, probar LI, contar. F3
  4. dim = cardinal de cualquier base, y un subespacio nunca supera al espacio. F4, F5
  5. Coordenadas en el orden del enunciado, en columna. F6
  6. Polinomios y matrices: a coordenadas y determinante. F7
  7. Columnas de P: el origen escrito en el destino. F8
  8. PB₁→B₂ multiplica coordenadas en B₁, y se chequea reconstruyendo el vector. F9
  9. La inversa vuelve; numérica, con calculadora. F10
