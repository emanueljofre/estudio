Números complejos

Módulo de un complejo

Enunciado

Dado z = 4√2 (cos2π + i·sen2π), hallar el módulo de w = z / (1 + i) + 2√2 i − i37.

Conceptos clave
  • Forma polar → binómica: z = r(cosθ + i·senθ). Con θ = 2π (vuelta completa): cos2π = 1, sen2π = 0 → z = r (real puro).
  • División de complejos: se multiplica numerador y denominador por el conjugado del denominador. El conjugado de (1 + i) es (1 − i), y (1+i)(1−i) = 1² − i² = 1 + 1 = 2.
  • Potencias de i (ciclo de 4): i¹=i, i²=−1, i³=−i, i⁴=1. Entonces iⁿ = i^(n mod 4). Acá 37 = 4·9 + 1 → i37 = i¹ = i.
  • Módulo: |a + bi| = √(a² + b²).
  1. Pasamos z a binómica. z = 4√2 (cos2π + i·sen2π) = 4√2 (1 + i·0) = 4√2 (queda real).
  2. Resolvemos la división z/(1+i) multiplicando por el conjugado: 4√2/(1+i) · (1−i)/(1−i) = [4√2(1−i)] / 2 = 2√2(1−i) = 2√2 − 2√2 i.
  3. Reducimos la potencia de i: i37 = i¹ = i.
  4. Sumamos todo (cuidado con el signo del − i37): w = (2√2 − 2√2 i) + 2√2 i − i = 2√2 + (−2√2 i + 2√2 i) − i = 2√2 − i. Los términos imaginarios ±2√2 i se cancelan.
  5. Calculamos el módulo: |w| = √[(2√2)² + (−1)²] = √[8 + 1] = √9 = 3.
Respuesta modelo

w = 2√2 − i  ⟹  |w| = 3.

⚠ Error típico

El −i37 NO es +i: como i37=i, ese término aporta −i. Olvidar el signo deja w = 2√2 + 3i mal. También revisá 37 mod 4 = 1, no 0.

Determinantes · propiedades

Hallar x y construir C

Enunciado

a) A, B ∈ ℝ³ˣ³, |A| = 5, B = x0903xx15−1. Hallar x para que |3 (A²)ᵀ B⁻¹| = −15. Justificar las propiedades.

b) Para cualquier x hallado, escribir una matriz C tal que |C| = −|B|.

Propiedades de determinantes que vas a usar
  • Escalar: |k·M| = kⁿ·|M|, con n = orden de la matriz. Acá n = 3 → |3M| = 3³|M| = 27|M|. (¡El 3 NO sale directo!)
  • Transpuesta: |Mᵀ| = |M|.
  • Potencia / producto: |A²| = |A|².
  • Inversa: |M⁻¹| = 1/|M|.
  • Permutar 2 filas/columnas multiplica el determinante por −1 (clave para la parte b).
a) Despejar |B| con las propiedades
|3 (A²)ᵀ B⁻¹| = −15dato
⟹3³ · |(A²)ᵀ| · |B⁻¹| = −15escalar + producto
⟹27 · |A|² · (1/|B|) = −15transpuesta + potencia + inversa
⟹27 · 25 · (1/|B|) = −15|A| = 5
⟹675 / |B| = −15675 = 27·25
⟹|B| = 675 / (−15) = −45despejamos |B|
a) Calcular |B| en función de x y resolver

Desarrollamos por cofactores sobre la primera fila (el 0 del medio ahorra cuentas):

|B| = x·(−1)² 3x15−1 + 9·(−1)⁴ 03x15
|B| = x(−3 − 15x) + 9(0 − 3x)menores 2×2: 3(−1)−15x ; 0−3x
|B| = −3x − 15x² − 27x = −15x² − 30xdistribuimos y agrupamos
−15x² − 30x = −45igualamos a |B| = −45
⟹x² + 2x − 3 = 0÷ (−15) y ordenamos
⟹x = (−2 ± √16)/2 = (−2 ± 4)/2 → x = 1 ó x = −3fórmula resolvente
Respuesta · a)

x = 1 ó x = −3. (Ambos valores dan |B| = −45, por eso "cualquier x".)

b) Construir C con |C| = −|B|
La idea

|B| = −45, así que buscamos |C| = −|B| = −(−45) = 45. Como permutar dos filas (o columnas) cambia el signo del determinante, tomamos B (con x = 1) y permutamos una vez → su determinante pasa de −45 a +45.

B = 109031115−1 — permutamos columna 1 ↔ columna 2 → C = 019301151−1

Verificación: |C| = 0·(0·(−1)−1·1) − 1·(3·(−1)−1·15) + 9·(3·1−0·15) = 0 + 18 + 27 = 45 ✓

Respuesta · b)

Por ejemplo C = 019301151−1  cumple |C| = 45 = −|B|. (Cualquier permutación simple de filas/columnas de B vale.)

Matrices · inversibilidad

¿Es inversible C = A² − 3Bᵗ?

Enunciado

Sean A = 1−103 y B = 03−21. Decidir si C = A² − 3Bᵗ es inversible.

Conceptos clave
  • Criterio de inversibilidad: una matriz cuadrada es inversible si y solo si |C| ≠ 0.
  • Producto de matrices: elemento (i,j) = fila i · columna j (suma de productos).
  • Transpuesta Bᵗ: las filas pasan a columnas.
  • Determinante 2×2: |[a,b],[c,d]| = a·d − b·c.
  1. Calculamos A² (= A·A):
    A² = 1−103 1−103 = 1−409
  2. Transponemos B y multiplicamos por 3:
    Bᵗ = 0−231 ⟹ 3Bᵗ = 0−693
  3. Restamos: C = A² − 3Bᵗ:
    C = 1−409 − 0−693 = 12−96
  4. Determinante de C: |C| = 1·6 − 2·(−9) = 6 + 18 = 24.
  5. Conclusión: como |C| = 24 ≠ 0, C es inversible.
Respuesta modelo

C = 12−96  con |C| = 24 ≠ 0  ⟹  C es inversible.

⚠ Ojo con la solución oficial

El slide oficial escribe "|A| = 6 − (−18) = 24", pero es una errata: el determinante que importa es |C| (la matriz que se evalúa), no |A|. El número (24) y la conclusión son correctos.

Sistemas de ecuaciones

Clasificar según el parámetro k

Enunciado

Determinar k ∈ ℝ para que el sistema tenga: a) infinitas soluciones, b) ninguna, c) una sola. Clasificar los tres casos.

− x₁ + 3x₂ + x₃ = 2
4x₁ − x₂ + 2x₃ = −1
5x₁ + 7x₂ + k·x₃ = 4
Conceptos clave · Rouché-Frobenius
  • Se compara el rango de la matriz de coeficientes con el de la ampliada (con la columna de términos independientes):
  • rg(coef) = rg(ampl) = nº incógnitas → SCD (solución única).
  • rg(coef) = rg(ampl) < nº incógnitas → SCI (infinitas).
  • rg(coef) ≠ rg(ampl) → SI (sin solución).
  • Truco rápido: el caso crítico ocurre donde det(coef) = 0. Acá det = −11(k − 7), que se anula solo en k = 7.
Eliminación de Gauss sobre la matriz ampliada
−1312 4−12−1 57k4
F2 + 4·F1F3 + 5·F1 → −1312 01167 022k+514
F3 − 2·F2 → −1312 01167 00k−70
  1. La última fila dice (k − 7)·x₃ = 0. Todo depende de si k − 7 es cero o no.
  2. Clave: el término independiente de esa fila es 0. Por eso nunca aparece una contradicción tipo 0 = (nº ≠ 0) → el sistema jamás es incompatible.
CondiciónQué pasaClasificación
k = 7 La fila 3 queda 0 = 0: sobra una ecuación, x₃ es libre → infinitas soluciones. SCI — infinitas
ningún k El independiente de la fila 3 es 0; no hay forma de obtener 0 = c≠0. SI — imposible
k ≠ 7 x₃ = 0 y se despejan x₂, x₁ hacia atrás → una única solución. SCD — única
Respuesta modelo

a) Infinitas soluciones ⟹ k = 7 (SCI).

b) Sin solución ⟹ no existe tal k: el sistema es compatible para todo k (la fila crítica tiene independiente 0).

c) Solución única ⟹ k ≠ 7 (SCD).
